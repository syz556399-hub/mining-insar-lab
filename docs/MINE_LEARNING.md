# 自己的矿区范围模型

这是在公开方法核对与本地实验之后新增的**独立实现**。训练使用本项目概率积分法、
合成 DEM、水体和复数观测生成的数据，不读取第三方源码、数据或预训练权重。
网络从随机初始化开始。它面向矿区范围分割，不是 DDNet/PUNet 复现。

## 流程与任务

`mine_learning.py` 连接五个步骤：

1. 生成数值干涉相位、干净形变相位、地形、水体和合成范围标签。
2. 按独立工作面几何分组划分 128/32/32 个训练、验证、测试场景。
3. 使用 sin/cos 两通道学习范围分割；另设干净形变相位回归头。
4. 在相同数据、初始化、增广顺序和训练预算下，对照辅助损失权重 0 与 0.2。
5. 按合成验证 IoU 选择候选，冻结权重后可用最终 LabelMe 标注做真实开发诊断。

全分辨率空洞残差网络来自本项目已有独立网络设计，两个输出头分别输出范围 logits
和形变相位周期数。没有先缩小整幅影像再找小目标，也没有把热图中心外扩当作最终范围。
这里只改变辅助损失权重，可描述为本轮单因素对照；单种子、少量数据仍不足以给出稳健结论。

## 标签和损失

- 范围标签：`abs(clean deformation phase) >= π/2`，BCE＋Dice，全部像素监督。
- 相位辅助：`clean deformation phase / (2π)`，加权 Smooth L1，权重 `1+4*range_mask`。
- 联合损失：`range_loss + 0.2*phase_loss`；对照组辅助权重为零。
- 相位辅助保持绝对周期幅度，不按每景最大值归一化。
- 空间旋转、镜像同时作用于输入和两个标签；相位符号翻转同时作用于有符号辅助标签。
  相位起点随机改变输入，不移动干净形变的零位移基准。
- 训练混合连续角度与 16 档显示码；验证、测试固定 16 档。编码不是恢复 GAMMA 物理相位。
- 水体、低相干或强噪声不会自动擦除真值。极低相干目标可能不可识别，报告不隐藏这些失败。

π/2 只是本轮声明的**合成范围代理**。它不等于人工可见条纹的最终边界；
无法因合成 IoU 高就断言真实范围正确。原始垂直位移标签仍由基础模拟器保留，
该实验保存的是范围任务所需的数值子集，没有更改基础模拟器默认标签。

辅助相位头预测的是**干净形变贡献**，不是含大气、轨道和地形的总相位解缠。
相位误差使用浮点弧度 RMSE 与全零基线；彩色缠绕显示可能掩盖整周误差，不能据颜色评价解缠。
无辅助训练组的相位头没有训练，其数值不构成相位预测能力。

## 生成场景

每份划分含单工作面、近距离双工作面、分离双工作面和无开采背景，
画幅范围为 850–5500 m、256×256 像素，三档干扰。工作面长度、宽度、埋深、位置、
方向等随机变化；调整煤层厚度后重新计算形变，目标为约 1.5–5.5 周，受物理参数界限约束。
不改变 RGB 图案或手绘掩膜来凑标签，不按外观或面积剔除样本。

`overlap` 和 `separated` 描述抽样几何，不承诺阈值后一定是两个/一个连通区域。
范围是语义联合掩膜，不把连通域数量当作真实工作面或矿区数量。
画幅分档用于覆盖不同像素大小，尚无真实像元间距与矿区参数校准。
DEM、水体均为合成；随机水体场景允许干旱，不能代替真实水系或水体概率统计。

## 运行

使用已安装训练依赖的 Python 环境，在工程目录执行：

```sh
python mine_learning.py generate --out runs/my_mine_range
python mine_learning.py train --out runs/my_mine_range --epochs 20
python mine_learning.py report --out runs/my_mine_range
```

生成/训练拒绝覆盖已经存在的结果。`manifest.json` 保存数值、参数摘要与分组标识；
`protocol.json` 在训练前固定两组方法与预算；逐轮记录、权重、全部测试预测和图版一并保存。
最早的验证最优轮次被选择，阈值固定 0.5，不用测试或真实标签选择轮次、阈值和候选。

如需真实开发诊断：

```sh
python mine_learning_real.py --run runs/my_mine_range \
  --source PATH_TO_ORIGINAL_INDEXED_BMP --labels PATH_TO_FINAL_LABELME_TILES
```

只接受通过调色板校验的原始索引 BMP；切片图像需与源图像素完全一致。
保持原始分辨率，以 256 窗口、192 步长做重叠融合。黑色显示码作为零输入向量，
不抹除预测、不改变真值。全部原始 shape 记录保留；重叠切片分别计数。
报告范围 IoU、精确率、召回率和逐记录覆盖，不评价 BMP 的定量形变相位。
开发使用过的日期不是独立测试；同一矿区不同日期也不证明跨地域泛化。

参考公开研究的合成数值数据、学习目标和任务分离思想，不使用其实现与权重：

- Wu et al. (2022), [Deep Learning for the Detection and Phase Unwrapping of
  Mining-Induced Deformation in Large-Scale Interferograms](https://doi.org/10.1109/TGRS.2021.3121907).
- Wang, Zhang & Wu (2023), [A Deep-Learning-Facilitated, Detection-First Strategy
  for Operationally Monitoring Localized Deformation with Large-Scale InSAR](https://doi.org/10.3390/rs15092310).

本项目的范围＋相位辅助损失不是上述论文公开的训练配方。复现实验与作者许可证约束的
材料保留在另一个本地文件夹，不进入本项目 MIT 源码包。
现阶段仍需真实数值相位、采样元数据、边界定义校准和独立矿区评价。
