# 模拟器重做：先验收影像与完整范围，再进入混合训练

目标是生成可作为训练集一部分的矿区干涉影像与完整沉降范围。当前 20 张只做外观、边界和导出验收，未训练新网络，也不能证明对任意真实干涉影像有效。

## 运行与文件

Python 3.11+，依赖 NumPy、Pillow。已有本工程可直接运行：

```sh
python simulator_review.py build --run runs/my_review --bmp my_reference.bmp
python simulator_review.py serve --run runs/my_review --port 8781
```

无索引 BMP 时省略 `--bmp`，使用本工程默认循环色表。服务仅监听本机。访问 `http://127.0.0.1:8781/`。

- `simulator_v3.py`：本工程独立实现的源模型调用、背景、观测与显示适配。
- `simulator_review.py`：生成 20 张、逐张审核、保存边界、保留旧版本、导出。
- `web/simulator-v3/`：简洁/高级界面、精确栅格画笔、同区域边界放大对照。
- `runs/<run>/manifest.json`：当前样本版本；所有旧文件夹原样保留。

20 个不同种子/几何场景：单盆地、重叠、分离、小目标、贴边与 2 张背景负样本。
4 张有少量合成水体，并非所有矿区都带水体。经首轮用户反馈，全部默认使用 BMP 风格；
研究图配色保留为降低亮度的对照显示。每个场景的不同显示始终属于同一组。

## 源模型与科学边界

3.2 版当前默认与已确认样本采用同一源生成方案：本工程的矩形工作面高斯影响积分、推进时间响应，再使用 `shape_warp=0.012` 的轻微低频坐标扰动。矩形开采积分不意味着条纹必须呈矩形；沉降影响函数和平滑尺度共同决定盆地轮廓。坐标扰动是经验形状增强，不能作为真实开采布局或地质过程报告。新生成的四张只对齐已确认样本的规则，不复制其图像、轮廓或审批状态。

另提供本工程独立实现的缓变采掘范围（`footprint=gentle`）作为备选：沿推进方向划为 48 个互不重叠的条带，中心线采用一次宽缓的二次弯曲，宽度采用缓慢锥度、宽缓鼓起和浅收腰。9 个节点由这些低频曲线计算，并非独立随机摆动。中心倾斜系数限于 ±0.10，弯曲系数限于 ±0.15，均以工作面宽度为相对尺度；浅收腰深度为宽度的 2–12%。这些是生成设计界限，并非反演的物理参数。各方案都计算固定两期 70/82 天的垂直沉降差。

该设计用于温和的不对称长圆、圆角块状轮廓；中心线斜率至多变号一次，避免反复折返。旧 3.1 的强随机节点方案 `irregular` 保留作历史重现，不作为默认场景。

这是一片聚合采空范围的离散近似，不把变化的中心线解释为真实单个工作面轨迹。节点、条带边界与种子写入 `mined_footprints`；沿推进方向不重叠，避免开采面积重复积分。条带数决定空间域与开采时间的离散误差，48 段不是经过现场验证的分辨率。常宽、无偏移条带在相同分段数下与原矩形算法逐像素一致。

高级模式可切换矩形工作面；未含 `footprint` 字段的 3.0 保存请求明确按矩形旧算法重现。既有批准样本与旧版本文件保留，新形态不会自动替换或批准它们。
LOS 距离增加为正，向下位移为正；观测入射角 33°、水平朝东，波长 0.055 m：

`LOS = down cos(33°) − east sin(33°)`；`phase = −4π LOS / wavelength`。

有效水平位移系数采用整个源场的平均影响半径乘梯度，是经验近似，未经现场标定。
为控制覆盖的条纹圈数，全部位移分量与形变相位使用同一个幅度缩放因子；因子写入元数据。
可选低频坐标扰动通过双线性插值改变盆地轮廓，属于形状增强，不作为严格概率积分预测或真实地质机理报告。
采掘范围、日期、幅度、波长、间距和增强参数均可追溯。这些变化改善几何多样性，不证明真实矿区统计已匹配。

背景是方向可变的相位斜坡、独立有限尺度谱随机场大气与合成 DEM 误差。
地形误差近似项为 `−4π B_perp DEM_error / (λ R sin θ)`，`R=850000 m`。
DEM 是合成谱场，水体是随机几何岸线；它们不是实测地形、DEM 水系或真实水体范围。
反射功率来自多尺度随机纹理及地形梯度的经验调制，不宣称复现某矿区地物或辐射定标。

观测使用单位方差圆对称复高斯对：

`z1 = sqrt(power) a`

`z2 = sqrt(power) [γ a + sqrt(1−γ²) b] exp(−i phase)`

`a,b` 独立，故期望交叉乘积为 `power γ exp(i phase)`。
独立复数对和空间格网分别平均交叉乘积与两期功率，最后才取相位。
空间相位梯度引起的额外相干损失是经验增强；样本相干性是平均复数相关系数幅值，不能等同无偏的真实相干性。
这是统计格网模型，不是完整 SAR 成像或从真实 SLC 估计的观测参数。

## 显示适配与数据隔离

索引 BMP 适配器只读取 16×16 色表和非黑亮度直方图，检查色表亮度可分解性。
合成观测功率的排序分位映射到该亮度分布；这是**经验显示域适配**，没有复制真实图块，
没有恢复真实物理相位，也没有反演真实相干性或证明纹理统计已匹配。
BMP 的相位零点、符号与尺度仍未知。黑显示像素不自动解释为水体或无效区。

本地首轮只读取已有的 1 月开发参考，没有读取保留的 4 月验证影像。
未来若更换统计参考，必须记录其来源与划分，不能用真实验证图拟合显示参数。
外部团队的例图仅用于观察显示方式，不进入本工程样本与导出。本工程不包含其模拟器代码、网络权重或生成数据。
实现独立不代表无需引用研究原理；概率积分法背景见 [REFERENCES.md](REFERENCES.md)，论文里的比较应引用对应原工作。

## 形态参考的范围

本地形态诊断使用 1 月开发 BMP 对应的最终 LabelMe 标注。连接区统计只描述栅格范围，不代表独立矿区个数，也不改动任何原始标注。该图 190 个连接区中，面积至少 100 px 的诊断子集为 185 个，PCA 轴比中位数为 1.46、25/75 分位为 1.28/1.78；仅用于限制过于细长或反复摆动的样本，不能推出真实工作面尺寸、埋深或全体矿区形态分布。诊断面积门槛不参与标签删除；裁图只作本地观察，不进入合成样本或训练导出。4 月保留数据未被读取。

Yu et al. (2022) 的济宁、淮北实测干涉图研究描述单盆地条纹近似同心圆或椭圆（Introduction；Figure 3）。这不说明所有矿区都如此，也不能用它把用户的偏斜、连接区标注改成规则椭圆。Tan et al. (2020) 的 Figure 12 展示八个长壁工作面构成的不规则开采区，是布局驱动不规则形态的例子。本工程不使用这些论文的代码、图像或已标注轮廓生成训练数据。

## 标签契约与审核

本任务预测完整沉降条纹范围，不是矩形检测框，也不是物理沉降阈值区。
高斯影响函数的尾部无限延伸，单凭模型没有唯一“可见外缘”。用户在放大对照中选择稍紧边界后，新样本默认候选线明确为：

`abs(clean spatially averaged deformation phase) >= 0.8 rad`。

这是待审核的支持轮廓设计值，约两个 16 色显示等级，不声称是已校准的真实外缘。
宽/当前/紧对照使用相同裁剪窗口，以半阈值、已保存的实际掩膜、双阈值展示；
对照只供观察，不会自动改变标签。缩放仅用于显示，不进入训练图。

用户可调整候选阈值或用画笔修边界，保留单像素、小区域和内部空洞；
程序不自动填洞、滤小目标、按水体/相干性删除标签。原有真实 LabelMe 标注不变。
画笔掩膜以原生画幅保存。之前的掩膜以内容哈希保存在 `mask_history/`，每次生成也保留旧版本。
确认同时绑定输入影像与标签的哈希；改变边界或重新生成后需要再次确认。
“外观合适”的文字反馈单独记录，不自动视作标签批准；工作台上的“影像合适，边界确认”按钮则记录明确审核。

## 导出与后续训练

预览包含全部 20 张并标为 `draft`。训练导出只包含当前版本已确认且哈希一致的样本：

```text
images/    一种选定显示，RGB PNG
masks/     同尺寸 0/255 单通道 PNG
arrays/    float32 形变、背景、观测、DEM、功率等
metadata/  参数、标签规则、审核、组号
labelme/   相同图像与精确栅格掩膜 JSON
manifest.json
load_dataset.py
```

`arrays.candidate_mask` 保留最初的候选支持区，**训练的最终标签使用 `masks/`**；
元数据记录是否手工修正及当前阈值。标签加载转换为 0/1，输入为 float32 RGB/255，
输出形状分别为 `[3,H,W]` 与 `[1,H,W]`。默认加载器拒绝未审核数据，调试草稿需显式 `allow_draft=True`。

数据没有提前随机拆片或自动划分训练/验证。先按 `group_id` 划分，再裁片/增强，
同源颜色变体不得跨划分；真实评估按独立日期/地点划分。大量合成数据应在外观和标签规则稳定后生成，
再与真实标注组成训练集，记录来源和比例，通过固定真实验证集比较真实单独训练与加入合成数据的效果。

## 已做验证

测试覆盖变宽条带退化为矩形时的逐像素一致性、旧版请求重现、条带非重叠约束、单位/符号与 LOS 一致性、复数相位空间平均、期望相关性、确定性、
噪声不改变源标签、负样本、原生掩膜/LabelMe 精确往返、内部空洞和单像素保留、
审核哈希检查、原版本保留与边界预览不改标签。它们验证实现契约，不证明真实影像泛化。

## 确认风格后的批量扩充

20 张全部明确确认且影像/掩膜哈希仍一致后，可使用本工程自己的批量入口：

```sh
python simulator_batch.py build --review-run runs/first_review --out exports/batch_500 --count 500 --seed 20261010
python simulator_batch.py validate exports/batch_500
python simulator_batch.py serve exports/batch_500 --port 8782
```

浏览器访问 `http://127.0.0.1:8782/`，每页 20 张，可按场景、划分和水体筛选，点击查看影像、边界和二值标签。生成器核心未修改；批量入口使用已确认样本的参数规则与新种子，不复制其影像或轮廓。强不规则、连续弯折方案不进入此批次。

温和变化包括区域边长 ±15%、条纹圈数 ±20%、目标相对尺度 ±10%、背景方向 ±35°、相干程度 ±0.03；相位背景、地形和噪声随独立种子变化。设计水体出现概率为 15%，不是对真实矿区水体频率的估计。具体界限、截断与种子见 `sampling_plan.json`，模板版本与确认哈希见 `baseline_receipt.json`。

全部新的自动标签统一为 0.8 rad 支持区候选规则，不把首轮手工修正推广为新图的人工真值。每张保持 `draft`，需抽查和必要的人工修正；`load_dataset.py` 默认拒绝未确认标签，初步实验需明确设置 `allow_draft=True`。这是对自动标签状态的保留，不影响其作为实验数据的读取。

500 张按场景类型分层为 400/50/50，每个独立源 group 只属于一个划分。新数据集的合成划分与真实数据划分分开；后续裁片、显示变体与增强继承源 group。合并多个批次时须检查重复 group，并保留跨批次划分一致性。文件与候选标签的一致性校验不等同人工外观验收或真实影像性能验证。

生成中断后，先检查原因，再在同一生成命令追加 `--resume --resume-note "原因与处理说明"`。程序检查计划、基准确认、现存文件完整性与哈希，继续新编号；不会覆盖已有图像或标签，也不会把不完整样本静默当作有效数据。继续事件和源代码哈希写入清单。显示循环端点使用 float64 取余量化，防止 float32 把微小负相位舍入到色表索引 16；此修复不改变数值相位、形变或标签。
